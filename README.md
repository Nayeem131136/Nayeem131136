## 🏆 Featured Projects

### 📄 [DocIntel: AI-Powered Document Intelligence System](https://github.com/Nayeem131136/docintel-ai-document-intelligence-system)
Reads PDF, image, Excel and CSV invoices (including scans and 1000-page PDFs) with OCR + LLM. Every extracted value is checked against the source text, so missing values stay empty instead of being guessed.
- ✅ **99.3% precision · 98.2% recall** on a labelled 116-invoice benchmark, **17/17** injected problems detected
- ⚡ 1000-page PDF processed in **12 seconds**
- 🧪 **239 backend + 39 frontend tests**, Docker Compose, GitHub Actions CI
- `Django REST Framework` `Celery` `Redis` `PostgreSQL` `RapidOCR` `Groq` `React` `TypeScript`

### 🎤 [Backstage: Public-Speaking Training App (Backend)](https://github.com/Nayeem131136/Public-Speaking-Training-App)
Internship project at Eutropia IT, where I lead a 4-member backend team. Users upload a speech; the API transcribes it and reports speaking pace, pauses and filler words.
- 🔐 JWT auth, owner/admin permissions, audio upload validation, processing-status lifecycle
- `Django REST Framework` `Simple JWT` `faster-whisper` `SQLite`

### 🎯 [CareerPilot AI: AI Career & Job-Matching Platform](https://github.com/Nayeem131136/careerpilot-ai-bd) · [Live](https://careerpilot-ai-bd.vercel.app/)
Lead Developer of the core platform (2-member team). Upload a CV in English or Bengali and get explainable job matches, scholarships and deadlines.
- 🔒 AES-GCM encrypted AI keys, per-user daily AI limits, data export/delete, Vercel cron jobs
- `Next.js 16` `React 19` `TypeScript` `Neon Postgres` `Drizzle ORM` `Better Auth`

### 🏫 [RoomEase: Smart Classroom Booking System](https://github.com/Nayeem131136/RoomEase)
Booking and routine management for UAP's 8 departments, replacing PDF/email room requests.
- 🛡️ Double-booking prevented by conflict detection + a **database-level uniqueness rule**
- 📥 Routine importer (PDF/Excel/CSV) with a review step before saving
- `Django 5.2` `SQLite` `Bootstrap` `pdfplumber` `openpyxl`

### 🧭 [CareCompass: Humanitarian Aid Coordination Platform](https://github.com/Nayeem131136/CareCompass)
Led a 3-member team. Connects citizens, volunteers and NGOs with GPS pin reporting and a full report lifecycle.
- 4 modular Django apps, custom user model, role-based dashboards, ORM-aggregated leaderboard
- `Django 5.2` `Leaflet.js` `OpenStreetMap` `Bootstrap 5`

### 🛒 [Zyvro: Streetwear E-Commerce Store](https://github.com/Nayeem131136/zyvro-official) · [Live](https://zyvro-official.vercel.app/)
Freelance client project: dynamic catalog, WhatsApp order hand-off and a Supabase admin panel with real-time order notifications and Row-Level Security.
